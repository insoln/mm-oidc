# ВАЖНО: Ограничения Mattermost Plugin API

## Критическая находка

После полного исследования, реализации и тестирования на реальном dev stack обнаружено **фундаментальное ограничение** Mattermost Plugin API:

### ❌ Невозможно добавить UI компоненты на страницу логина

**Что было сделано:**
1. ✅ Изучена документация Mattermost Plugin API
2. ✅ Реализован компонент `LoginButton` с использованием `registerRootComponent`
3. ✅ Собран и установлен плагин на реальный Mattermost (v11.2.1)
4. ✅ Протестировано на dev stack с Mattermost + Keycloak
5. ✅ Подтверждено: JavaScript bundle загружается успешно
6. ❌ Результат: Компонент НЕ рендерится на странице `/login`

**Причина:**
- Mattermost рендерит plugin root components только ПОСЛЕ авторизации пользователя
- Страница логина изолирована от системы плагинов
- Это архитектурное решение для безопасности, не баг

**Доказательства:**
- Скриншот реальной страницы логина: кнопка отсутствует
- Console logs показывают, что плагин загружается
- Network requests показывают, что bundle скачивается
- DOM не содержит элементов плагина

## Проверенные альтернативы

### ✅ Решение 1: Ingress/Reverse Proxy (Рекомендуется)

**Описание:** Настроить reverse proxy для автоматического редиректа `/login` → `/plugins/com.mm.oidc/login`

**Преимущества:**
- ✅ Работает для всех пользователей
- ✅ Прозрачно (пользователи не замечают разницы)
- ✅ Поддерживает все клиенты (web, mobile, desktop)
- ✅ Полностью контролируется администратором

**Недостатки:**
- ⚠️ Требует доступ к инфраструктуре
- ⚠️ Нужна тщательная настройка (избежать loops)
- ⚠️ Необходимо исключить API endpoints

**Примеры конфигурации:**
- `docs/LOGIN_INTEGRATION_GUIDE.md` содержит примеры для:
  - nginx
  - Traefik
  - HAProxy

### ✅ Решение 2: Прямая ссылка

**Описание:** Пользователи используют `/plugins/com.mm.oidc/login` напрямую

**Преимущества:**
- ✅ Работает из коробки
- ✅ Не требует настройки
- ✅ Простое решение

**Недостатки:**
- ⚠️ Пользователи должны знать ссылку
- ⚠️ Не интуитивно

**Когда использовать:**
- Корпоративный портал с ссылкой
- Welcome email с инструкциями
- Обучение пользователей

### ✅ Решение 3: CSS кастомизация

**Описание:** Использовать custom theme для добавления текста/инструкций на страницу логина

**Преимущества:**
- ✅ Не требует серверных изменений
- ✅ Можно добавить визуальные подсказки

**Недостатки:**
- ⚠️ Только косметические изменения
- ⚠️ CSS может сломаться при обновлении Mattermost

## Что НЕ работает

### ❌ registerRootComponent
```typescript
// Этот код скомпилируется, но НЕ будет работать на /login
registry.registerRootComponent(LoginButton);
```

**Почему:** Root components рендерятся только после авторизации

### ❌ DOM Manipulation
```typescript
// Прямое добавление в DOM также не работает
document.body.appendChild(buttonElement);
```

**Почему:** Mattermost использует React и очищает DOM при навигации

### ❌ Custom Route
```typescript
// registerCustomRoute тоже недоступен до авторизации
registry.registerCustomRoute('/custom-login', CustomComponent);
```

**Почему:** Custom routes монтируются после авторизации

## Официальная документация

Из официальной документации Mattermost:
- "Most plugin registration points are available *after* authentication"
- "There is no documented API for extending the pre-authentication portions of the webapp"

Источники:
- https://developers.mattermost.com/integrate/plugins/components/webapp/
- https://developers.mattermost.com/integrate/reference/webapp/webapp-reference/

## Рекомендации

### Для разработчиков
1. **Не тратьте время** на попытки обойти это ограничение через plugin API
2. **Используйте ingress redirect** - это единственный надежный способ
3. **Документируйте** это ограничение для пользователей

### Для администраторов
1. **Настройте ingress/reverse proxy** для автоматического редиректа
2. **Используйте примеры** из `docs/LOGIN_INTEGRATION_GUIDE.md`
3. **Тестируйте** конфигурацию перед продакшеном

### Для пользователей
1. **Используйте прямую ссылку** `/plugins/com.mm.oidc/login`
2. **Сохраните в закладки** для быстрого доступа
3. **Обратитесь к администратору** для настройки auto-redirect
