📋 Implementation Details

The Sign in with OIDC button appears automatically when:

  • Plugin is enabled in System Console
  • "Show Login Button" setting is enabled (default: true)
  • User is on the /login page
  • Plugin configuration is valid (Issuer URL configured)

When clicked, the button redirects to /plugins/com.mm.oidc/login which starts the OIDC authentication flow.
